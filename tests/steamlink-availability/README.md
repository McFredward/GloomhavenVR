# Native streaming availability integration

This bounded fixture compiles the exact production source-request expression,
options row filter, chroma-key dependency and open-pane capability refresh. It
covers unsupported saved-on preferences, the Frame standalone exclusion, manual
off, all Frame/transport/preference combinations, and asynchronous menu updates.
Public OpenVR identity and child-process lifetime are separate boundaries tested
by the connection reader's own fixture. This does not prove a headset identity,
a receiver installation, pixel correctness or Windows runtime output.
