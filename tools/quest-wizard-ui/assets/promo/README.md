# Publisher promotional artwork

These twenty-one unmodified images were publicly released by the Gloomhaven Digital
developer/publisher in its Steam announcements. They are included for the
builder's character/enemy slideshow so it is visible immediately and works
without a network connection. No artwork was extracted from an owned game,
AssetBundle, DLC or decrypted content bank.

The artwork remains the property of its original rights holders. The project's
open-source code license does not relicense these images. Original branding and
credits within the images are preserved.

`../../promo-artwork.json` records each exact public CDN URL, source announcement,
byte count, SHA-256, dimensions and constrained local path. On 2026-10-06 the original twelve images and the nine added images matched
their pins and were visually inspected.
The server revalidates the bytes and dimensions before serving them through its
authenticated local artwork route. The browser does not contact the CDN.

The original publisher announcements are:

- [Initial Early Access Character Previews, 2019-01-11](https://store.steampowered.com/news/posts/?appids=780290&enddate=1558613054&feed=steam_community_announcements)
- [Gloomhaven's Monster Madness, 2019-04-04](https://store.steampowered.com/news/posts/?appids=780290&enddate=1557410073)

The earlier `bandit-archer.jpg` pin pointed to the announcement's elite Bandit
Guard. It now points to the normal Bandit Archer reveal and retains the correct
caption. The new six reveals were checked against the publisher's original
announcement and visually inspected before pinning.

The 2026-10-06 expansion adds the seven other elite enemy reveals and the Bandit
Commander from the same Monster Madness announcement, plus the original
Nightcrawler Scoundrel promotional image from the publisher's 11 July 2019
"Free Skins for Mercenaries and an Updated FAQ" announcement:
https://store.steampowered.com/news/posts/?appids=780290&enddate=1564327021&feed=steam_community_announcements

All twenty-one bundled images retain original bytes and embedded marks. Their
exact public CDN URLs, source pages, dimensions, sizes and SHA-256 pins are in
`promo-artwork.json`. New pictures were visually inspected against the captions
and the publisher's original linked full-size reveals. There is no game-bank
extraction, raster editing or artwork download prerequisite for the player.
The requested product layout no longer displays a "Bildquelle" link; source
attribution remains here and in the release's included manifest.
