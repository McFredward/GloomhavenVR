# Publisher promotional artwork

These twelve unmodified images were publicly released by the Gloomhaven Digital
developer/publisher in its Steam announcements. They are included for the
builder's character/enemy slideshow so it is visible immediately and works
without a network connection. No artwork was extracted from an owned game,
AssetBundle, DLC or decrypted content bank.

The artwork remains the property of its original rights holders. The project's
open-source code license does not relicense these images. Original branding and
credits within the images are preserved.

`../../promo-artwork.json` records each exact public CDN URL, source announcement,
byte count, SHA-256, dimensions and constrained local path. On 2026-10-06 all twelve
source downloads matched those pins, and all twelve images were visually inspected.
The server revalidates the bytes and dimensions before serving them through its
authenticated local artwork route. The browser does not contact the CDN.

The original publisher announcements are:

- [Initial Early Access Character Previews, 2019-01-11](https://store.steampowered.com/news/posts/?appids=780290&enddate=1558613054&feed=steam_community_announcements)
- [Gloomhaven's Monster Madness, 2019-04-04](https://store.steampowered.com/news/posts/?appids=780290&enddate=1557410073)
