This preview release prepares the mod for its first major release and exercises the
installation and in-game update path.

- Multiplayer boards mirror original game widgets, card effects and animation transitions.
- Improved card fronts, rest and burn effects, card flights, and character decision displays.
- Reduced repeated work in multiplayer card capture, remote effects and board updates.
- Laser interactions respect foreground grab bars, and released windows turn smoothly toward you.

The full download includes the required VR assets. Everyone in a multiplayer session must
install the same release.

The latest multiplayer performance changes still need a full-party headset test. A previously
reported brief board disappearance during a long rest has not yet been reproduced or explained.
