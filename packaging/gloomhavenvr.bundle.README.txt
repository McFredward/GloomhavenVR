This zip was packaged WITHOUT the file gloomhavenvr.bundle. That file is NOT optional.
The mod still starts without it, but everything the mod draws in 3D lives inside that
file, so all of it is missing:

  * the hands — every glove model (leather, arcane, plate); you get crude placeholder hands
  * the control board / play tray, the card backing and the keycaps — flat placeholders
  * the map table and the parchment in the map room
  * the head avatars of the other players in multiplayer
  * the 3D environments (cellar, swamp) and the water — the game's own sky stays
  * every shader the mod ships (board lighting, glows and hex markers, the window
    dissolve, the water) — each effect that needs one is skipped
  * the controller models in the tutorial's controls lesson

The mod does not refuse to start and it does not crash: each part writes one line into
the log and falls back. It just looks wrong everywhere at once.

WHERE THE FILE GOES
  <Gloomhaven folder>\BepInEx\plugins\GloomhavenVR\gloomhavenvr.bundle

  That is THIS folder, next to GloomhavenVR.dll — the same layout INSTALL.txt describes.
  The file is about 75 MB. Nothing else to change; it is picked up at the next start.

HOW TO GET IT
  Download the release zip from
    https://github.com/McFredward/GloomhavenVR/releases
  Every published release contains the bundle. Extract the full release zip into
  your Gloomhaven folder, replacing the incomplete installation.

HOW TO CHECK IT LOADED
  Start the game once, then open <Gloomhaven folder>\BepInEx\LogOutput.log and look for
    [Info   :GloomhavenVR] [Hands] gloomhavenvr.bundle loaded from ...
  If instead you find
    [Warning:GloomhavenVR] [Hands] gloomhavenvr.bundle NOT FOUND at ...
  the file is not where that line says it looked. If you find
    [Warning:GloomhavenVR] [Hands] AssetBundle.LoadFromFile failed for ...
  the file is there but damaged; the rest of that line says how, and a fresh copy fixes it.
