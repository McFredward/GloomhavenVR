GloomhavenVR Quest Builder

DE
1. Das vollständige ZIP in einen neuen Ordner entpacken.
2. Windows: Quest-Builder.cmd per Doppelklick starten.
   Linux: im entpackten Ordner ein Terminal öffnen und bash Quest-Builder.sh ausführen.
   Das Startfenster geöffnet lassen. Python und die lokale virtuelle Umgebung werden eingerichtet.
3. Im Wizard die eigene Gloomhaven-PC-Installation wählen und den Hinweisen folgen.
   Unity Hub kann eine Anmeldung und die Aktivierung einer geeigneten Lizenz erfordern.
4. Falls unterbrochen: Wizard erneut starten. Der gespeicherte Vorgang öffnet sich automatisch;
   mit "Fortsetzen" dieselbe Auswahl und erhaltene Ergebnisse weiterverwenden.
   Der Arbeitsordner bleibt auch bei einem neuen Builder-Paket erhalten:
   Windows: %USERPROFILE%\.ghvrq; Linux: ~/.ghvrq.
5. Bei einem Fehler: im Wizard "Diagnosepaket speichern" wählen und das ZIP dem Fehlerbericht beilegen.

EN
1. Extract the complete ZIP into a new folder.
2. Windows: double-click Quest-Builder.cmd.
   Linux: open a terminal in the extracted folder and run bash Quest-Builder.sh.
   Keep its launch window open. Python and the local virtual environment are set up for you.
3. Select your own Gloomhaven PC installation in the wizard and follow its prompts.
   Unity Hub may require sign-in and activation of an eligible license.
4. If interrupted, open the wizard again. Its saved session opens automatically;
   use "Continue" to retain the same choices and verified results.
   Keep the workspace when replacing the Builder package:
   Windows: %USERPROFILE%\.ghvrq; Linux: ~/.ghvrq.
5. If a step fails, choose "Save diagnostic package" and attach the ZIP to your bug report.

Requires Windows x64 or Linux x86_64, your own PC game installation, internet for tool setup, and substantial free disk space.
Linux needs a desktop session and the system libraries required by Unity, Git and the native build tools.
