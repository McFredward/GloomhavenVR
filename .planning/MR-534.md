# Cold Guildmaster table visibility in mixed reality — build 534

## Evidence and cause

Local Debug logs identify ModBuild 533 / assembly 1.0.5.0. Peer logs remain historical
build 500. No new screenshot accompanies this report. The user observes a missing table
on first Guildmaster entry in MR, with the table retained after changing environments.

LogOutput.log:6527 identifies the existing native `GH_Map_Table`: a complete mesh with
legs, 1.67 x .851 x 2.03 metres, with its top only .004 metres below the parchment.
The optional leg/slab finder rejects its thickness; that does not establish absence.
At :6580, MR explicitly disables that same Standard-shader renderer as sky/background.
Its world bounds are 366.91 x 186.72 x 444.78, centred at (-69.16, -93.42, -.23).
During initial seating those scaled bounds enclose the camera and pass all three size
thresholds. The old comment claiming a table cannot enclose the head was incorrect.
The missing campaign-slab asset warning is a separate unsuccessful optional fallback,
not evidence that the native table is missing.

## Change

Exclude the native GH_Map_Table, GH_Map_Bench and GH_Map_Barrel asset families before
sky-name and enclosing-bounds classification. This requires neither MapRoomDriver readiness
nor a stable head/rig scale, so the very first MR sweep retains the real geometry. Sky/cloud
renderers retain existing classification; no background geometry is added to the play area.
The Guildmaster lane recognizes whole native table support before optional slab loading,
avoiding the misleading warning and possible duplicate geometry. See GUILD-534.md.

## Validation

The MR runtime harness extracts the complete production IsSkyRenderer, NameLooksLikeSky,
NameHasHint and sky-name table, and compiles the actual furniture predicate. Cases cover the
captured bounds during cold seating, the later head position, campaign tabletop names,
bench/barrel families, named clouds, shader-detected clouds, anonymous enclosing sky,
non-enclosing props and thin map surfaces. Removing the production furniture exemption
fails the captured cold-table assertion. Existing UI-only backing retirement checks remain.

Focused total: 79 assertions, 26 bindings and six negative controls. Integrated results
are recorded in STATE.md. Headset appearance remains to be verified.
