## Snapshot and rendering contract

Record 47 and active-bonus animation record 49 retain their shipped meanings. Record 50 is one complete auxiliary slot at a time: bar 1–3, slot 0–7, actual actor, public model selector, bounded original subcontrols and at most 16 original animator setting entries. Each internal TLV payload is at most 255 bytes; the full inner codec cap is 2048 bytes. The root integration owns the six-byte packet header, envelope 8, independent address streams, fair queues and late source sampling. A clear is explicit and slot-local.

No private ability-card ID, card name, art ID, arbitrary text or shader property name is transmitted. The original `IAbility.ID` is deliberately excluded because native implementations embed private ability-card identity. Public effect/action Guids select already replicated configuration. Receivers match full actor, bar, slot, model kind, Guid and augmentation guards before writing.

Sampler caches keep reflected field bindings and unchanged immutable snapshots. Animation values are sampled after owner layout/animation writes. The receiver uses retained source-time history and the shared bounded playback clock, without extrapolation or an invented interpolation over an idle gap. Rebuilding native layout does not restart a retained animation. Original resting geometry is restored before fitting; owner animation values are applied last.

The inert native source stage is updated before **every** live mirror sync. Previously a newer owner snapshot could be painted once, then overwritten on the next frame by a stage that only refreshed at the slower content cadence. The immutable paint gate no longer leaves that intervening frame stale.

## Integration review follow-up

The shared presentation queue previously retained only the first waiting snapshot and its latest successor. Under backlog, an intermediate clear could be overwritten by a same-identity reopening. Both ends now use the bounded `PresentationPending` policy: retain opening, the latest identity boundary's predecessor and successor, and the newest sample. Sender identity metadata covers partial active-bonus row changes, auxiliary slot clears/replacements, and native board generations. The queue finishes any in-flight fragmented packet before advancing. Dedicated vectors verify sender reconstruction and receive coalescing for `A → clear → A`, partial bonus-slot absence, and returning to an earlier identity. The focused local wire run passed 218110 assertions with temporary shared dependencies and registration; those shared files were excluded from this lane's commit.

The native element-board lane receives an explicit `SetOwnerFrame(sizePixels, parentPixels)` mirror API. It uses the sampled owner's committed native envelope and parent frame before any viewer-local dock measurement, through the same density fit. Zero clears this optional input. Other mirrors are unaffected. The board lane owns the descriptor, generation matching and final original rect writes.

A second integration review found that the legacy five-second fragment lifetime was shorter than the weighted cosmetic scheduler's maximum delivery time. Dedicated cosmetic streams now opt into a 32-second assembly lifetime; the existing Presence default and all gameplay/network disconnect timeouts remain unchanged. `PresentationSaturationVectors` keeps all 24 auxiliary streams plus Presence, bonus animation, plume and board streams saturated at their complete transport size caps, injects announcements, and ticks at both 90 Hz and 18 Hz. Every stream completes byte-exactly inside the bounded extended lifetime, while the old five-second assemblers demonstrably lose frames. The local suite passed 220640 assertions including these vectors.

The final board integration review found overlapping native material writers: an element's UIFX and multiple GUI animators could each retain a different owned copy of the same Graphic material, so the last assignment discarded another writer's shader property. Mapped animation writers now accept a shared clone-owned material dictionary. Native elements and auxiliary use-bar animators share that cache, and the containing clone destroys it once after its writers. Release compilation passed with zero warnings and errors; actual Unity material rendering remains a multiplayer runtime check.
