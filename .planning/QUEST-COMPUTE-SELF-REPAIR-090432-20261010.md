## Actual source defect

The native compute producer writes HLSL and metadata with the platform-native
newline convention, then records hashes of the actual resulting complete bytes.
The retained Linux project has13 shaders/36 original kernels, each matching its
source manifest. Windows writes CRLF. The C# multiline pragma expression ended
with `$`, which leaves the preceding carriage return unmatched. The validator
therefore reported an empty kernel declaration census as changed original order,
even though its earlier complete source/metadata hashes had passed.

Correct parsing handles native line terminators without rewriting source bytes,
changing the producer or weakening names, order, macro or thread-group identity.
The independent audit also identified the same source defect in the downstream
exact original-null material Shader pointer expression. Both consumers are
repaired together to avoid merely moving this known platform failure to the
next validation stage.
