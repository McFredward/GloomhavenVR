## Source causes and bounded changes

A complete newer original replaced older complete metadata, but an obsolete
cumulative delta queued behind that original vetoed supersession of the entire
older urgent bundle. That delta required the old baseline even when a strictly
newer complete current original already replaced both. The receiver could
assemble a bundle quickly and still wait for the actual current picture.

`ExtrasSendQueue.SupersedeTownOriginal` now cancels only strictly older revisions
of the exact same lane, public claim, session, service and module. A genuinely
newer delta that still names the old baseline preserves that baseline. The lane
bundle similarly keeps unchanged required originals and meaningful dependency
affinities, while permitting obsolete full/delta members to leave. Ordinary
stream fairness, opening-page limits, byte budgets, codecs and authority are
unchanged. This does not send pixels or introduce another picture representation.

A current census could remove a pooled holder while explicitly retaining its
original child modules. Disposing the holder destroyed those observer children
through Unity ancestry. Their existing packet sequences then prevented immediate
remounting until another header arrived. Before removing a holder, the mirror
now reparents only children listed by the current census outside the retired
ancestry with their displayed world geometry intact. Their current packets
become eligible to remount under the current original. Removed cards/controls
still retire immediately; a true owner close clears the complete picture.

The same preservation occurs before a validated original parent replacement.
Candidate validation/application still completes before disposal. Native output
may legitimately receive a new clone when a detached partition changes its
required Canvas wrapper; clone reference identity is not the visual contract.
Current original content, alpha, geometry and rendered visibility are.

## Why prior green evidence missed this case

The previous in-flight fixture changed titles after starting a complete old
picture. It did not enqueue an actual cumulative original-artwork delta while
that old complete bundle remained fragmented. That missing mixed dependency was
the exact cancellation veto. An already complete33-original initial snapshot
also omitted the actual pre-offer census growth. Admission age0 and first-bundle
assembly were additionally weaker clocks than a complete original image rendered
from the real current owner capture.

The new bounded runner reuses the original native source exports and existing
first-picture path, but adds that actual mixed full/delta debt and a13→33/35
pre-offer census. A431ms minimum separates the pre-offer phase from mounting;
editor/JIT and first-fragment work can make this phase longer. The1s deadline
starts at actual current offer capture, includes capture/deserialize/apply/native
asset validation/Canvas/render/readback, and is unchanged. No admission-age clock
or per-child relaxed deadline replaces it.

## Rejected hypotheses and fixture limitations

`census-fixed/run-mbod5ifq` passed45-frame continuity but incorrectly required the
same clone reference after a legitimate Canvas-type change. That assertion was
replaced with current visible native output, not a relaxed visibility check.
The failed growth runs `run-aojv5paq`/`run-bts96vyi` were a fixture delivery error:
forcing a current native refresh created baseline8 for Aura2, but the fixture
only delivered the generic child's refreshed original. Aura delta13 correctly
waited for baseline8 while the observer only retained baseline2. Delivering the
actually emitted refreshed originals fixes the setup. Production baseline
validation is not weakened and the failed receipts remain.

A proposed stale wrapper/root tween reset was rejected. ReadCanvasFrame skips
non-manifest native parents, so the real retained nested wrapper has no active
header geometry tween in this reproduction. Its original node's Host-relative
path remains valid because the Host world basis is preserved. The initial
unfinished-wrapper precondition failure is retained (`run-jaeuybvc`). No new
TownServiceMotion API or broad animation Reset is shipped. Child alpha/color
and native motion clocks remain independent.

The runner is one Unity editor engine with an explicit two-peer sender boundary,
not two headsets or a real Bolt session. Card-model population and lazy template
keys are explicit fixture adapters; real original widget hierarchies, packed
native SpriteAtlas pixels, callbacks-disabled Freeze/Warm/Resolve, codecs,
scheduler and receiver are retained. Its llvmpipe wall-clock pass does not
promise a universal WAN latency or prove headset pictures. Root integration
still runs common affected transport/source checks and the combined native
motion/flight cases; this worker does not repeat the full suite.
