the corresponding guard and environment fixture. Shared pillar removal and the
actual smaller desktop bank are documented separately. Original Campaign
extraction, payload producer identities, roles and simplification algorithms are
unchanged.

The generator now discards only a pillar's retired50/0 bytes, metadata and tier
receipts, retaining its exact100 completion. The current aggregate compiler
input and authored compiler project also prune those exact filenames; unrelated
geometry stays intact.

mesh into a new derivative namespace. A finite compatibility rule recognizes
only the reviewed B712 predecessor:
`9f9d09d30837555ce694e2e2eb82f88b83ab6f35def79041979ba1d2ea489fd4`,8,535 bytes.
It replaces the exact retirement block with the predecessor's original loop and
checks the entire reconstructed source hash/length. Additional edits anywhere
else do not qualify. Roles and geometry remain part of the derivative identity.
Thus existing non-pillar tiers and exact pillar100 receipts can be reused without
running simplification; the new generated-art receipt still records the actual
current source producer.

Migration accepts that exact predecessor, same owned game, source-bundle census
and unchanged retained immutable rows. Only its generated index/source receipt
may change; each must contain the recognized old or already-copied new bytes.
Missing intermediate records after an interruption can be copied again. The
old owner is replaced last. Unknown owner/source/content drift keeps its normal
rejection instead of being excused by the retirement rule.

roles/geometry helper closure into its isolated source root. An import failure
