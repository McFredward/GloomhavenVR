## Mod updates

IL2CPP code cannot be updated by swapping a DLL. A private code-only Unity
project compiles the current woven game and mod without importing original
textures, models or scenes. It uses the actual Android package APIs, original
UGUI batching repair, plugin classifications, script execution orders and Both
input configuration. TextMeshPro remains the original plugin; pinned3.0.6 shader
sources do not add a second runtime package.

Native code and global metadata replace each other as a matched pair. Every
retained original MonoScript assembly/name/property hash/execution order must
match the actual compact player. Original initializers/assembly classification
remain qualified. Completed SDK, weave, package API and native outputs have
separate receipts. Packaging retries reuse the closed native pair.
Successive mod versions share a private code project's Unity/Bee Library only
for the same converted game and package ABI. Its small code tree refreshes;
Unity invalidates changed native objects. Build receipts remain per-update and
unowned/linked compiler directories are rejected. This reuses compiler work
without treating an earlier mod's native pair as the current completed output.

Changed authored VR art rebuilds its own banks. Unchanged banks and the original
Campaign bank remain untouched. Original-derived environment inputs use a
separately owned partial snapshot. Follow-up comparisons use current signed
update.mod instead of restoring the original conversion's older mod.
Native program/interop source changes, package ABI changes, original script
layout changes and additional DLC content require a full build with a clear
error rather than an incompatible fast update.

## Profile and APK patching

New full builds and qualified code updates include a bounded APK-signed profile.
A Quest-only initializer loads its offline name/ID/provider/DLC snapshot before
scene Awake. Remote identities retain real network tokens. No store/cloud
services are added. A legacy APK needs one code migration of its baked constants;
later compatible profile edits need no Unity. Profile edits retain the current
mod and cannot add DLC absent from the original converted bank.

Targeted Resources TextAssets and binary Android version attributes have exact
registry/object/readback checks. Other serialized objects retain raw bytes.
Unchanged ZIP members are copied compressed, without reinflation/recompression.
Signing/certificate verification precede atomic publication. Updated APK
identity remains original game input key plus current mod build.

## Signing and headset content

Android requires the original signing key to update an installed app. The
original workspace retains `build/signing`. Another workspace selects that
folder's `quest.keystore` and `local-key.json`; an APK alone cannot recover the
private key. Missing/wrong keys stop before compilation. Secrets remain local
and excluded from APK/support data. The installer never uninstalls to bypass a
certificate mismatch, preserving the existing save directory.

APK-only updates may omit the adjacent Campaign bank only when its exact
completed content receipt and full file inventory already exist on the Quest.
The installer checks this before `adb install -r`. A new headset still requires
the original content bank/full build. Existing saves are not rewritten.
