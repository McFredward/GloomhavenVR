# Town-service presentation transport

Implementation checkpoint, 2026-09-21. Not a hardware-complete feature claim.

## Integration

`Net.TownServices.TownServiceMirror` owns owner-scoped native widget modules. Root integration
registers original templates with `RegisterTemplate(service, template, original, exclude)`;
the exclusion predicate removes separately registered sections and dynamic rows. TMP-generated
submeshes are excluded automatically and regenerated by the retained original TMP widget.
Templates are cloned below an inactive bank before `RemoteWidgetMirror.Neutralize` removes
native controllers, callbacks and input. It never opens a service on the observer's behalf.

Call `BeginSession(service, session, sharedFrame, stationAnchor)`, then `RegisterModule` for
each live source. Stable module IDs span ushort except65535 (manifest); the simultaneous
module count is bounded to192. Each module has at most256 original hierarchy nodes. Call
`UnregisterModule` when a row leaves the visible catalog, and `EndSession` at native closure.
The existing final native presentation pass calls `Capture`; callers must not also capture it.
Set `SharedFrameForRemote` to the matching shared map-frame resolver. Remote session metadata
includes owner sample time, session age, service and station pose for shared NPC authorship.

Parent-module/node bindings retain original clipping and fades when row modules are detached
from their containing native template. Root ancestor alpha is carried separately and stops at
the nearest registered module parent. Observer modules have no raycasters or selectable input.

## Wire and recovery

Message19 carries additive TLV78, with message20 fragment envelopes using existing TLV48 or
lossless compression64. Wire version remains3. Full modules and cumulative deltas share a
bounded60000-byte codec; repeated property/material values are pooled inside a snapshot.
Delta references name a complete baseline, not a chain of earlier animation samples. Missing
baselines are inert until a repeated complete snapshot arrives. Manifests describe the complete
active module set, so dropped close packets recover through repeated manifests and timeout.

Each sender/module has an independent bounded assembler. Low16 sequence bits identify its
module, including the manifest. The global864-byte/50ms scheduler cap remains unchanged;
town services use three additional weighted turns and empty streams cost no existing turn.
Queued module boundaries retain the full baseline before its coalesced cumulative deltas.

## Evidence and remaining work

The focused harness executes the production codec and delta code:50,234 assertions cover
every truncated packet prefix, invalid numeric/text/identity data, Unicode, foreign input,
missing baseline, skipped deltas, changed topology and close manifests. Synthetic payloads:

| Sample | Raw | Deflate |
| --- | ---: | ---: |
|256 nodes,64 original labels |40,217 B |4,767 B |
|One changed appearance property against that baseline |134 B |69 B |
|16-node inventory row |3,654 B |626 B |

These are codec measurements, not captured native-window traffic or headset performance.
Sampling allocation reduction, actual native hierarchy/asset completeness, transport stress
tests and owner/observer rendering review remain in progress at this checkpoint.

Known strict limits: generated RenderTextures need an explicit model-aware `Assets.Register`
binding on both clients. Native textures use unique loaded descriptors because Unity's import
content hash is editor-only; ambiguous descriptors fail instead of choosing artwork. Custom
non-uGUI renderers, independently simulated particles, unsupported shader properties and missing
original templates are not silently reconstructed. These must be resolved before claiming
complete visual parity for a populated service. Local native operation never waits on remote
template/asset readiness or NPC animation.
