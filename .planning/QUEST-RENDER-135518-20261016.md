## Proton server NLS failure

native log says `wineserver: failed to load l_intl.nls`; a later procedural request
finds no running worker. The pinned native receipt already contains the5,564-byte
NLS file, SHA256`ad190cb85aa387d3d92a9d97ff254e20bf982a2ea9c11c2cad651ba0f8d20584`.

executable from Android's native-library directory therefore searches the wrong
read-only installation tree, instead of the retained Wine data root.

server child. The bridge adapts only that proven server's `/proc/self/exe`

libc. No Wine code/data, FEX package, game graph or DLL is changed. The original
twelve exports and protocol remain intact. Source references:

- [Pinned server path discovery](https://github.com/GameNative/proton-wine/blob/555aa70febb7d36e82d96697b554ff8f4fe0bb1a/server/unicode.c#L262)
