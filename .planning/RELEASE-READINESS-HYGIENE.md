inventory and a cleanup record, not a release approval or an asset-rights audit.

1,341 under `unity/`, 741 under `src/`, 223 under `.planning/`, 107 tests,

as distributable source, and environment files were not opened.

| `prebuilt/`, Unity source assets, `libs/RefAsm/` | Retain unchanged | Required release/build inputs. The 16 reference assemblies are intentionally tracked metadata-only build references; source ownership and redistribution remain part of the separate publication audit. |

A filename-reference scan found **no unreferenced top-level `scripts/` entry**.
That scan is supporting evidence, not a complete dead-code analysis. Three files
in the two cloth-cook harness snapshots are byte-identical (`Builder.cs`,
`CookCostBench.cs`, `ColliderSyncBench.cs`), while `ClothBench.cs` and
`ScaleShapeBench.cs` differ. These are separate historical experiments, so no
partial snapshot was dismantled. Rendered board tiles under
`unity/asset-preview/render/` are build inputs for the settings/documentation
pipeline and were retained.

No tracked `bin/`, `obj/`, Unity `Library/`, `Temp/`, editor cache, patch rejects,
backup files or credential-named files were found by the path inventory. Unity
license request/activation suffixes (`*.alf`, `*.ulf`) are now ignored to avoid
future accidental staging. This path check does not claim that arbitrary file
contents or Git history contain no private information.
