# NPC661 exact return-root packing

The final full-root policy exposed two independent sender defects. The frozen
6e5c93b4d codec needed eleven events for the seeded 64-member capacity case; a
bounded larger-prefix search reduced that to ten, still above the existing
eight-event assertion. In mixed traffic, ordinary-tail backoff could cross a
native cohort's atomic boundary and discard the entire cohort even though exact
packing had already proved that core fit. No discarded source was marked sent,
but repeating the same selection prevented return progress.

Matched private Unity ledgers retained the original seed, cadence, every root,
deadline and fairness assertion. Frozen6e admitted nine of seventeen mixed
children and then ordinary-only 179-byte events. Larger-prefix search without
the protected core admitted no mixed children through the original deadline.
The protected core fixes that starvation. Its exact old-floor control fails the
unchanged `.267s` assertion; all 120 continuously dirty ordinary/live/fan roots
still receive turns after the fix.

## Additive115 schema

Record 98, record 113 and wire version 3 retain their grammars. Record 115 has the
existing bounded compressed chunk layout: version 1, transformed length,
compressed length, contiguous offset, then at most 248 compressed bytes. Each
length/offset is little-endian UInt16. The first 21 bytes retain the exact outer
record 97 source clock. Deflate and CRC32 cover the complete transformed buffer,
including its unchanged clock; CRC is explicitly over the transformed bytes.

The private expanded representation preserves original record order and all
record 113 bytes. A matched record 97 Kind 1 body temporarily becomes Kind 129:
cohort ordinal, member index, the literal twelve bytes for parent module,
binding, parent alpha, visibility and hand, a ten-bit nonzero-word mask and
canonical UInt32 varints for the exact IEEE XOR against that member's transmitted
Child pose. Every canvas flag and optional 85-byte canvas recipe remains literal.
Kind 129 exists only inside 115, never in the original97 grammar.

Identity uses the complete lane/service/session/public-claim/module/structure
tuple. References resolve only to a unique transmitted Child in the same packet;
ambiguous cohorts are refused. The inverse uses integer bits, never floating
arithmetic, TRS reconstruction or a prior packet. After restoring the full 97/113
buffer, the ordinary native parser validates every original property. Both the
transformed and reconstructed buffers retain 8192-byte bounds; native logical
entries retain 128 and each event retains864 bytes.

The sender uses 115 only when an exact same-packet return-root representation
compresses better. Ordinary packets bypass its parser. Record 98 remains the
existing fallback, and its current writer bytes equal the compiled frozen6e
writer for the maintained deterministic fallback recipe.

## Proof and limitations

`python3 scripts/npc661-return-packing/run.py --source-root . --output-dir <dir>`
binds current production through the maintained native loader. It executes the
unchanged Capacity/Mixed scenario and invokes that exact compiled DLL for the
committed real raw packet fixtures, literal98/115 vectors and byte proofs. The
fixtures come from the actual seeded Capacity658 serializer; their SHA256 values
are verified before use. The capacity scene uses generic Unity child transforms
and exact numeric capture, so this is transport/recipe evidence, not a headset
appearance proof.

The full capacity suite passes 221 assertions. All 64 children finish in eight
Mono events of 848,844,851,862,853,862,846 and855 bytes. Mixed 17 finishes in two
events; all 120 contending originals progress. A separate focused original
old-cohort-priority control still fails its unchanged fairness assertion.

The maintained byte proof passes 1880 assertions. It restores every97/113 byte,
tests 70/71/156-byte roots, nondefault parent/binding/alpha/visibility/hand and
the full canvas recipe, multiple disjoint cohorts, ambiguity refusal and actual
old 98 writer equality. Every truncation is refused. Each single-bit mutation is
refused or restores exactly the unchanged original bytes; two accepted mutations
affect nonsemantic Deflate framing bits. Valid-CRC bad references/masks, mixed
98/115 streams and expansion bounds are checked. Unknown sibling extensions
retain the same original result. The historical 6e size control compiles and
fails the named unchanged 864-byte assertion; the exact old-core-floor control
fails the original native lifetime assertion.

Supported mod compatibility remains exact ModBuild. There is no new capability
negotiation or handshake delay. Motion broadcasts also run before version
announcement and with VersionGuard disabled; an older reader skips 115 and
rejects a clock-plus-115-only packet with no entries. Cross-version presentation
with that best-effort override is not promised. Normal flat peers keep their
native game presentation.

This change does not establish universal first-picture latency or hardware
parity. The separate cold first-picture diagnostic remains an explicitly red
performance boundary. Native visual fields, contents, membership, source times,
flights, fonts and already stable overlays are not substituted or trimmed.
