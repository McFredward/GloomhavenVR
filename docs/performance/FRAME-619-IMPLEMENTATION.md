# Build619 Frame follow-up

Hardware baseline: the latest Build618/c108555cd Frame capture, with two loaded
scenarios and a CampaignMap interval. [Analysis](FRAME-619-ANALYSIS.md) distinguishes
native loading, preparation, settings and ordinary play. It does not provide a
matched hardware FPS gain for the changes below.

## Loading indicator

[Preparation](FRAME-619-LOADING.md) batches already-ready metadata and shares the
portrait deadline instead of spending one alternating frame or a fresh wait on
every original owner. Expensive texture/geometry work stays bounded. Actual
native room visibility, procedural jobs, material completion and queued visual
preparation re-arm the spinner for new rooms. Existing shared card/figure caches
stay alive, and original input, loading flags and continuation are untouched.

## Whole-game detail coverage

[Coverage](FRAME-619-DETAIL-COVERAGE.md) derives cosmetic ownership from all 188
original character bundles/190 model trees and the complete nested PCG database
census. Living Spirit ordinary/elite particles and mesh eye bands are included.
Heroes, summons, bosses and other enemies use the same policy. Exact native
identities protect core bodies, native gameplay presentation and callbacks; an
unknown object does not become optional because of its shader or name alone.
Policies also cover later room/material readiness and local/remote held figures.

## Walls and healthbars

[The rendering report](FRAME-619-BARS-WALLS.md) separates native HIGH shader
bytecode evidence, actual material/property delivery and Unity pixel fixtures.
Progressive native solid/held masks retain original shaders, endpoints and
foundation behavior. Actual Windows/Frame shader execution still requires
hardware confirmation. Healthbar materials use the original TMP font/submesh
routes as well as ordinary Graphics, so the circled number shares the bar's
selected depth policy. Original materials, clipping and masks are restored.

To A/B the environment simplification use **Graphics → Simpler environment
shading** (`Einfachere Umgebungsschattierung`), or:

```ini
# BepInEx/config/dev.gloomhavenvr.perf.cfg
[Optimize]
ScenarioSimpleEnvironmentShading = false
```

This restores simplified environment materials live. Actual masonry/water were
already excluded from this optimization, including in the baseline capture;
this toggle is not a switch between a cheap wall shader and the PC wall shader.

## Graphics controls

[The audit](FRAME-619-GRAPHICS-AUDIT.md) records ordinary choices, Advanced tuning
and eleven retained INERT compatibility keys. Four one-shot buttons apply
Standalone, Performance PC, Balanced PC or High-End PC using existing VR controls
and the original initialized native graphics owner. Standalone uses fresh-Frame
constants including native Fastest. No old preset index is reactivated; later
manual edits stay authoritative. Pure work removal and stereo safety no longer
have off switches that add work without an intended quality benefit.
