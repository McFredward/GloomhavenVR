## Wrist attachment and multiplayer

The feature is opt-in through VR Options; the existing follow/fixed preference
and ordinary board placement remain saved. The complete original board follows
the selected tracked wrist, without parenting it under replaceable hand visuals.
The default is the non-main hand; Advanced exposes hand, metre offsets, degree
angles and uniform size. Entry/exit use the existing short grab-bar tween timing.
The attached board hides its complete Follow/Fixed control and grab bar.

The existing fast rig-board record 70 sends the actual owner-authored pose and
world scale. Additive v3 TLV 100 carries only the attachment visibility flag;
old ordinary packets remain unchanged. Observers use the original board geometry
and owner result, never their own wrist settings. Intermediate movement is carried
by the same stream as the existing board. No new card-face or concealment rule is
introduced. See [the feature contract](../design/WRIST-BOARD.md).
