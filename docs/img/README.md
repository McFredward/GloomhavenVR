## Keeping them small

A GitHub README is read on phones and on metered connections. Aim for **under 5 MB** per clip:
3–6 seconds, one idea per clip, roughly 720 px wide, 15–24 fps, cropped to the action. Capture
one eye only — a stereo capture is twice the pixels for no benefit on a flat page.
