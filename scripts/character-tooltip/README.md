# Character-window tooltip clearance

`run.py` builds complete current production DLLs into isolated private outputs,
then executes their original tooltip patches in Unity2021.3.5f1/OpenGLCore. It
requires the task-private ADB environment. Repeatable `--case` selects a bounded
subset; a subset does not certify the complete repository gate.

The native skin, campaign description/conceal and creator perks references are
read from real GH.Runtime components. `audit-native.py` independently pins the
original scene/controller/field authoring, including pointer/gamepad variants,
the original600px personal-quest explanation and every native creation tooltip.
Identity never comes from scene-object names or translated tooltip text.

The live native controllers are dormant except the actual
UILocalTooltip.Show/Hide/RefreshPosition path. Converted-window membership, the
VR-running observation and original UI camera are explicit inputs. The complete
production TooltipWindowPatches, TooltipOnWindow raise/restore and right-side
layout execute. Shared hints exercise the production owner resolver and frame
placement method with explicit shown/anchor observations; native UITooltip fade
animation and gameplay services are not started by this fixture.

Checks cover yaw/scale, source identity, ordinary same-name negative scope,
creator information/perks, native quest reuse and native hide, late width/height,
fixed host size, cached warm ownership, grace-latched placement and unchanged
button callbacks. Actual world-canvas pixels show the personal-quest body/text
beside an opaque rendered foreground volume. Artwork/text are controlled inputs,
not exported game artwork or a headset/D3D11/Vulkan acceptance claim.

The new head-space menu capture is independently owned by the rendering lane. Its
integration must retain the original local annotation outside HostRect without
expanding the physical window or forcing a larger planar UI photograph.

Every invocation reaps its Editor/compiler processes and uses the central
cleanup_completed_run API. The exact pinned InputSystem Remote source namespace
is retained byte-for-byte outside Library first, because the unchanged retention
API otherwise treats that package directory name as protected hardware evidence.
Logs, results, source pins, executed DLLs and captures remain. Loose movie/story
Content is not copied into these private builds; embedded resources remain.
