# Original merchant caption proof

Run `python3 scripts/merchant-caption646-runtime/run.py` from the checkout.
Requires the game's read-only GH_Data, Unity2021.3.5, the UnityPy environment and
an X display supplied by xvfb. Output is gitignored under
`.planning/debug/merchant-caption646/`.

This bounded proof compiles the production caption helper and exact final Entry
presentation method with production capture, codec and observer binding. The
original serialized merchant row is exported, including27 nodes and actual
sprites. Price/quantity/discount/affordability and warning outputs exercise96
states locally and remotely, repeated source overwrite and4 clone rebuilds.
Three causal controls must fail: small text, duplicate name/icon and missing Entry
application. Native glyph bounds, actual visible pixels and matching readbacks
are required; two blank pictures cannot establish parity.

The existing source-to-clone mirror is a declared port implemented with real
property capture/binding. Native economic callbacks are not executed. TMP uses
the equivalent editor font atlas; imported original hierarchy/colours/sprites are
retained. This is neither a hardware/network latency proof nor a complete-suite
pass. See `.planning/NPC-646-MERCHANT.md` for exact evidence and rejected attempts.
