and defect controls; `--case production` is explicitly partial. The native bank
is reproduced byte for byte before execution. Its actual mesh, material and encoded
textures load in Unity2021.3.5. The original Windows shader uses an explicit GL
witness because those encoded programs cannot execute in this editor.

The backdrop cross-check executes exact original FlatScreen opaque-material
construction, depth/queue tuning, owned opaque-coverage cache and reversible
ready-menu material kernels. Already-present native RT/window ownership and native
mode/hand diagnostics are explicit ports. The unchanged original Overlay shader
executes; no test shader substitutes for the window material. Single and split
surfaces run front/rear with native RT alpha zero, the real native sky/depth reset,
a later opaque room surface and physical hand geometry in front of and behind the
