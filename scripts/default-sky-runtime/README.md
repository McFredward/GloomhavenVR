# Native Default sky and actual menu backdrop

`python3 scripts/default-sky-runtime/run.py` runs the complete local Unity scope
and defect controls; `--case production` is explicitly partial. The native bank
is reproduced byte for byte before execution. Its actual mesh, material and encoded
textures load in Unity2021.3.5. The original Windows shader uses an explicit GL
witness because those encoded programs cannot execute in this editor.

The backdrop cross-check executes exact original FlatScreen opaque-material
construction, depth/queue tuning, owned opaque-coverage cache and reversible
ready-menu material kernels. Already-present native RT/window ownership and native
mode/hand diagnostics are explicit ports. The unchanged original Overlay shader
executes; no test shader substitutes for the window material. Single and split
surfaces run front/rear with native RT alpha zero, the real native sky/depth reset,
a later opaque room surface and physical hand geometry in front of and behind the
window. Head pixels prove the image/foreground depth, and the actual coverage
getter rejects foreign visible materials and shaders. Leaving/reentering readiness
must preserve the original material identity and restore the intro shader/queue.

The scope also retains native sky arrival/visibility authority, rig replacement,
style/MR stand-down and VR exit controls. It does not bootstrap the native game's
menu controllers, certify native AMP D3D11 fragment art, OpenXR/frame scheduling,
headset appearance or complete mixed-reality coverage masks. The companion
menu-world-runtime suite exercises actual world-wrapper placement and controls;
this fixture concentrates on its shared sky/window material/depth seam.

Every attempt retains logs, input/source/assembly evidence and head captures, then
stops private editors and fd-proven escaped compilers before completion-cache
cleanup. A short private TMPDIR and ADB socket isolate concurrent editor runs.
