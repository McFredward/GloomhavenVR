# Starter-card wheel dispatch proof

Run from a private worker with the project/native references initialized:

```sh
TMPDIR=/dev/shm ADB_SERVER_SOCKET=tcp:localhost:5073 \
  python3 scripts/ugui-scroll760-runtime/run.py
```

Production stick response, wheel-owner lookup/delivery and `UiScrollFocus`
execute against real Unity `EventTrigger`, `ScrollRect` and `GraphicRaycaster`.
The native asset audit independently verifies the original full-card adapters
and starter-viewer list. Controls cover the original failure, real/custom
handlers, inactive handlers and the stick deadzone. `--case` selects a bounded
repair rerun. Logs, source/native/assembly pins and cleanup receipts remain in
`.planning/debug/ugui-scroll760-runtime`; project caches are removed after exit.

This is a focused UI proof. It supplies tracked input and settled hover rather
than starting the game or claiming Windows/headset acceptance.
