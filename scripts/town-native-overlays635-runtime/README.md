# Serialized enchantress overlay proof

Run `python3 scripts/check-town-native-overlays635.py` from the integration tree.
Worker verification can explicitly bind a pending mask file with `--mask-source`;
the exact bound text hash and its path are retained in the receipt. Such a worker
receipt does not certify a different final integration tree.

This proof imports the game's actual eleven-node `CardHilight` hierarchy from
`level4` GameObject2849, including its original ring sprite, stretched graphic
anchors and pooled `UIEnhancementButtonHighlight` prototype GameObject2040. Game
data stays read-only. It reproduces native pooled parenting with
`worldPositionStays=true`, and retains a pooled card's prior yaw, which the game's
card pool does not reset. Source overlay corners and ring coverage/plane are
checked against the physical print before comparing owner and observer output.
Two equally incorrect pictures therefore cannot pass those source checks.

The original fitting, template capture, bounded packed numeric wire codec,
offered-print affinity, property playback and per-render interpolation execute
from production source. Separate original aura and ability-area partitions are
delivered with delayed independent holder headers. Every intermediate area plane
must remain on the physical print while the visitor turns; native hover/selected
fill opacity and rendered ring phase remain shared. Observer originals are inert.
PNG renders and per-subframe geometry are retained alongside source hashes.

Five counterfactual controls remove print affinity, substitute a wrong print
binding, retain the obsolete pooled world basis, apply physical card size a
second time to the already-fitted ring, or restore the incorrect sibling plane
despite the print's retained yaw. Each must fail its corresponding geometric
assertion. The production host has the uniform metres-per-pixel scale written by
`CanvasConversion.PlaceHost`; artificial three-dimensional shear is not labelled
as a hardware cause.

The full ability-card model, native animation/hover clock and native activation
are declared fixture inputs. Ring pixels use the original sprite with the editor's
UI shader; this is not a proof of the game's custom effect shader or headset
pixels. The original native-controller lifecycle and laser callback are tested
separately. This proof uses production owner/observer playback in one Unity process
with independently mounted originals; it is not a network latency or separate
process artwork-registry proof. The current supplied remote hardware logs predate
Build634 and cannot validate the repair.
