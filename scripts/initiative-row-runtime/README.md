# Native initiative row regression

Run `python3 scripts/check-initiative-row-runtime.py`. Sparse worker checkouts may
pass `--asset-root` pointing to the read-only integration checkout's original
Overlay shader. `--baseline` runs the two expected failure witnesses against
unchanged old production; it is not passing production coverage. `--case` selects
partial evidence.

The existing initiative-binding fixture ports the slide, pin and fit hold; it
cannot observe an entry-plane failure inside the real slide. This new small
Unity project therefore compiles the complete production InitiativeReorderSlide,
WorldSurface, tray dock, surface Tick/LateTick/OnConverted/Release, fit hold, depth
normalization and hierarchy inventory. It executes original GH.Runtime.FirstPass
LeanTween IL, actual Unity2021.3.5 layout/clocks/uGUI, and final head-camera pixels
through the original Overlay shader. One project serves all compiling controls;
the qualified local invocation took 40.21 seconds with one editor instance.

Native actors/phase data, diagnostic-only Chronos reads, host acquisition, popup/texture setup and unchanged
portrait pin presentation are explicit boundaries. The native world-X producer
uses original LeanTween.moveX/easeOutQuad and the game's slot/sibling ordering.
Editor batchmode cannot service WaitForEndOfFrame, so an explicitly labeled EOF
phase port binds the original coroutine's source order to the following real
Unity Update. The original LeanTween frame guard remains active. The fixture
does not run the scenario rule engine or advance gameplay. Its
independent real Unity layout computes final slots, and a depth-writing plane
plus head pixels distinguishes in-plane originals from displaced entry roots.
Colored image sentinels measure canonical portrait-center pixels; they do not
reproduce the original artwork. A read-only UnityPy export verifies the actual
native player/enemy prefab roots have authored Z=0 and scale=1 before compiling.
Nested portrait depth, actor identity/callbacks, actual duration/curve, paused
Unity time, manual board movement/scale and lease teardown are checked.

The six production cases cover changed membership by addition/removal, a paused
clock, adoption of an already-moving native row, a late-observed ordinary rising
flag and membership abort before a subsequent batch. Seven independently
compiling controls remove plane restoration, conversion priming, the safe rising
condition, abort priming, first-frame restoration, easeOutQuad or release abort.
Each must reach its named runtime assertion. Baseline evidence remains separate
from these controls and retains the untouched Build756 source identities.

The public old screenshot, later minor-offset comment and shared Build753 log
recording remain different observations. A reproduced source defect does not
establish which historical trigger the reporter encountered. This fixture does
not certify Photon, four headsets, D3D11 or the separate issue27 turn stall.

Every invocation retains source/native/toolchain hashes, original logs, captures
and causal results, then uses cleanup_completed_run after reaping its processes.
No shared references, other worktrees or hardware evidence are cleaned.
